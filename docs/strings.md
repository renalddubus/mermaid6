# Inventaire des textes de Mermaid6

État du code au 23 septembre 2026. Textes de l’application, messages, accessibilité, catalogue et sources des exemples. Les fragments dynamiques gardent leurs expressions entre `${…}` ; le contenu saisi par l’utilisateur et les erreurs générées par Mermaid ne peuvent pas être énumérés.

Les textes sont listés par fichier, avec leur numéro de ligne. Des fragments peuvent être assemblés à l’écran (par exemple « Mermaid » + « 6 »). Les libellés encore présents dans `appearance.ts` ne correspondent plus à des contrôles visibles dans l’éditeur.

L’[inventaire brut](strings-complet.json) contient aussi les chaînes techniques non vides du code TypeScript/TSX : chemins, sélecteurs, identifiants et configuration (ainsi que les deux métadonnées éditoriales de `index.html`). Il exclut les dépendances, les tests, les commentaires et la documentation.
